# C 语言学生成绩管理系统

这是一个 Visual Studio 2022 的 C 语言控制台项目，使用链表保存学生数据。

## 项目结构

- `main.c`：登录、注册、菜单和功能入口
- `link.c`：学生链表、统计、排序、查询和文件读写
- `link.h`：学生结构体和函数声明
- `test.c`：账号注册、登录和修改
- `students.txt`：示例学生数据

## 打开方式

1. 双击 `1121.1.sln`。
2. 选择 `Debug | x64`。
3. 按 `F5` 构建并运行。

编译环境：Visual Studio 2022，并安装“使用 C++ 的桌面开发”工作负载。

## 登录与注册

项目启动后可以先注册账号，再用账号登录。

账号保存在本地 `user.txt` 中。该文件已加入 `.gitignore`，不会上传到仓库。

## 已实现功能

1. 录入学号、姓名、语文、数学、英语成绩
2. 统计每门课程的总分和平均分
3. 统计每个学生的总分和平均分
4. 按总分从高到低排名
5. 按总分从低到高排名
6. 按学号升序排列
7. 按姓名排序
8. 按学号查询排名和成绩
9. 按姓名查询排名和成绩
10. 按优秀、良好、中等、及格、不及格统计课程人数和百分比
11. 输出全部成绩和课程汇总
12. 将学生记录保存到 `students.txt`
13. 从 `students.txt` 读取并显示

## 数据文件

`students.txt` 每行保存一个学生：

```text
学号|姓名|语文|数学|英语
```

例如：

```text
1001|张三|90|85|88
```

## 修改科目

当前科目数量由 `link.h` 中的 `COURSE_COUNT` 控制，科目名称在
`link.c` 的 `COURSE_NAMES` 中定义。

如果增加科目，需要同步修改：

1. `COURSE_COUNT`
2. `COURSE_NAMES`
3. `link.c` 中文件保存和读取的字段
4. `main.c` 中学生录入的输入项
5. 输出表格的表头
